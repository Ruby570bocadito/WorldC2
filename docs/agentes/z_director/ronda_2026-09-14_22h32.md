## Decisiones tomadas por ti en esta ronda

1. **`collab:read` universal en lugar de abrir `collab:write`:** el write de notas/profiles sigue siendo de operador; solo la lectura se universaliza. Un permiso nuevo en lugar de reutilizar `sessions:view`: los perfiles de agente no son datos de sesión, y un permiso con nombre propio documenta la intención.
2. **La auditoría del resto de superficies se registra sin hallazgos:** validación de comandos (agent_id/command requeridos, timeout default 30s, persistencia+audit del task), módulos (sanitización de nombres, HMAC sobre serialización canónica, rechazo de manifests manipulados), JWT (pinning de HS256 antes de confiar en claims), vault (solo `credentials`, nunca `server_secrets`), SPA (filepath.Clean + guard /api/) — todo sólido tras nueve rondas.
3. **El select-all de Files respeta el filtro:** seleccionar "todo" con un filtro activo marca solo las filas visibles — el comportamiento menos sorprendente para una acción destructiva.
4. **Baseline re-registrado:** build ✅, vet ✅, gofmt vacío, suite `-race` verde (8 paquetes), `npm run build` OK. Smoke RBAC 4/4.
